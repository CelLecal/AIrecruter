## 🎯 Описание проекта

Процесс найма водителей в транспортных компаниях часто упирается в рутину: проверку водительских удостоверений, оценку стажа и заполнение договоров.

**AI-рекрутер** автоматизирует этот процесс на 90%, внедряя искусственный интеллект и технологии распознавания документов (OCR) в привычный процесс подбора персонала.

### 💼 Бизнес-легенда (Кейс)

_Проект разрабатывался под заказ для региональной логистической компании на аутсорсе. Цель — сократить время оформления одного водителя с 3 дней до 15 минут за счет автоматического сканирования документов и ИИ-оценки кандидатов._

---

## ✨ Ключевой функционал

- 🧠 **AI-скрининг кандидатов:** Автоматический анализ резюме соискателей, сопоставление со спецификациями вакансий компании и умное ранжирование кандидатов.
- 📸 **Проверка документов через OCR:** Автоматическое распознавание паспортов, водительских прав и медицинских справок при загрузке фото. Проверка на соответствие требованиям (категории прав, стаж).
- 📄 **Автоматизация документооборота:** Мгновенная генерация пакета трудовых договоров и соглашений на основе распознанных данных.
- 🔒 **Защищенная авторизация:** Разграничение прав доступа (кандидат / рекрутер / администратор).

---

## 🛠 Стек технологий

- **Frontend:** React (Vite), TypeScript, Tailwind CSS (современный адаптивный UI).
- **Состояние и роутинг:** React Router DOM, Context API.
- **Сборка и линтинг:** ESLint, Vite.
- **Деплой / Инфраструктура:** Vercel (CI/CD настроен на автодеплой из ветки `master`).
